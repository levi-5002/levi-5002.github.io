PHP 文件包含漏洞详解：从原理、LFI/RFI 到伪协议与包含利用

本文用于 Web 安全学习、CTF 靶场以及授权渗透测试。请勿在未授权的网站或服务器上进行漏洞测试。

文件包含漏洞是 PHP Web 安全中非常经典的一类漏洞。它的核心问题并不复杂：程序允许用户影响“服务器要加载哪个文件”，但又没有对这个文件路径进行严格限制。

一个普通的文件读取问题可能只能让攻击者看到文件内容，而文件包含的危险之处在于：PHP 的 include、require 等函数在加载文件之后，还可能按照 PHP 代码进行解析。

因此，文件包含漏洞往往不仅能够造成敏感文件泄露，在满足一定条件时还可能进一步演变为代码执行。

  • 使用白名单，而不是单纯黑名单
  • 禁止用户输入直接进入 include/require
  • 使用 realpath() 后验证最终路径
  • 限制文件访问目录

  • 生产环境关闭详细 PHP 错误输出

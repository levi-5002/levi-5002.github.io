渗透测试信息收集：从企业资产发现到 ARL 自动化资产梳理

授权说明： 本文仅用于合法授权的渗透测试、安全评估、SRC/漏洞赏金规则允许的目标以及自建实验环境。任何主动扫描、目录枚举、漏洞探测或验证行为，都应先确认目标范围、请求强度和授权边界。

信息收集的目标不是“扫描得越多越好”，而是回答三个问题：资产是谁的、资产暴露了什么、这些暴露面之间有什么关系。

信息收集最容易出现的问题，是把 WHOIS、OneForAll、Wappalyzer、Nmap、FOFA 等工具分别记成一堆命令，却不知道什么时候应该使用它们。

实际上，它们属于同一条连续的资产发现链路：

因此，信息收集不应被拆成互不相关的工具和命令，也不适合简单套用 OSI 七层模型。更实用的思路，是沿着“资产归属 → 域名 → DNS/CDN → Web 指纹 → Web 入口 → 端口与服务”的链路逐层展开。
